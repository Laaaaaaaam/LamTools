## ✨ 功能特性

### 📁 媒体管理
- **多格式支持**：MP4, WebM, MOV, MP3, WAV, PNG, JPG 等
- **拖拽导入**：支持文件拖拽到导入区域或直接拖到时间线
- **缩略图预览**：自动生成视频缩略图和音频波形
- **媒体信息**：显示分辨率、时长、文件大小等元数据

### 🎞️ 时间线编辑
- **多轨道**：视频轨道(V1)、音频轨道(A1)、文字轨道(T1)
- **片段操作**：拖拽移动、左/右裁剪、分割、删除
- **磁吸对齐**：自动吸附到其他片段边界和播放头位置
- **剃刀工具**：快速分割片段
- **缩放控制**：时间线缩放，精确到帧级别编辑

### 🎨 视觉特效
- **实时滤镜**：亮度、对比度、饱和度、模糊、色相旋转
- **预设特效**：复古、黑白、戏剧化、梦幻等一键应用
- **变换控制**：位置、缩放、旋转、透明度
- **播放速度**：0.25x ~ 4x 变速播放

### ✍️ 文字叠加
- **丰富排版**：字体、大小、颜色、粗细自由设置
- **描边效果**：可配置描边颜色和宽度
- **背景设置**：文字背景色和透明度
- **独立轨道**：文字层独立于视频，方便管理

### 🔄 转场效果
- 淡入淡出、溶解
- 左/右/上/下擦除

### ↩️ 撤销/重做
- 最多50步历史记录
- Ctrl+Z / Ctrl+Shift+Z 快捷键

### 📤 视频导出
- **格式**：WebM (VP9)
- **分辨率**：1080p / 720p / 480p / 360p
- **帧率**：24 / 30 / 60 fps
- **质量**：可调节视频比特率
- **实时进度**：显示导出进度条

### ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Space | 播放/暂停 |
| S | 分割片段 |
| V | 选择工具 |
| Delete | 删除片段 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+A | 全选 |
| ← → | 逐帧移动 |
| Shift+← → | 1秒移动 |
| Escape | 取消选中 |

## 🚀 快速开始

### 方式一：直接打开
直接在浏览器中打开 `index.html` 文件即可使用。

### 方式二：本地服务器
```bash
# Python
python3 -m http.server 8080

# Node.js
npx http-server -p 8080

# 然后访问 http://localhost:8080
```

> 💡 推荐使用本地服务器以获得最佳兼容性

## 🛠️ 技术架构

- **前端框架**：原生 HTML5 + CSS3 + JavaScript (ES6+)
- **视频渲染**：Canvas 2D API
- **视频导出**：MediaRecorder API
- **音频处理**：Web Audio API
- **UI设计**：深色主题，类似专业NLE软件布局

### 模块设计

```
App (主应用)
├── MediaManager    → 媒体文件导入与管理
├── Timeline        → 时间线核心逻辑
├── Preview         → Canvas 实时预览渲染
├── Properties      → 属性面板交互
├── Effects         → 滤镜与转场
├── Export          → 视频编码与导出
└── History         → 操作历史管理
```
