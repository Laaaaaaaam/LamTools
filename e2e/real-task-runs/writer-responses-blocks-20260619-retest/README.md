# hello_tool

A tiny CLI greeting tool using only the Python standard library.

## Install / Run

No external dependencies are required. To run:

```bash
python hello_tool.py
```

Pass an optional name argument:

```bash
python hello_tool.py Codex
```

## Sample Output

```bash
$ python hello_tool.py
Hello, World!

$ python hello_tool.py Codex
Hello, Codex!
```
